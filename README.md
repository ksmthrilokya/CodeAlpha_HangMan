# CodeAlpha_HangMan

A simple text-based Hangman game built in Python as part of the CodeAlpha Python Programming Internship.

## About
The player guesses a word one letter at a time. The game uses a small list of predefined words and allows a maximum of 6 incorrect guesses.

## Key Concepts Used
- random
- while loop
- if-else
- strings
- lists

## How to Run
1. Open `Hangman.ipynb` in Jupyter Notebook
2. Run all cells
3. Follow the prompts to guess letters and try to win the game
